# Real Estate Website (Laravel)

A web-based Real Estate Management System developed using **Laravel**.  
The project provides property listings, broker management, appointments, and user authentication.

## Features
- User Authentication (Login, Register, Profile Management) using Laravel Breeze
- Property listing and rental view
- Broker management
- Appointment booking (session-based)
- Admin panel (protected by authentication)
- Responsive frontend pages

## Tech Stack
- **Backend:** Laravel 12, PHP 8.2
- **Frontend:** Blade Templates, Bootstrap
- **Database:** MySQL
- **Authentication:** Laravel Breeze

## Project Structure
- `app/Http/Controllers` – Application controllers (Property, Broker, Appointment)
- `resources/views` – Blade view files
- `routes/web.php` – Web routes
- `database/migrations` – Database schema
- `public/` – Public assets
